# AGENTS.md — Math Trainer

Проект: русскоязычный математический тренажёр, ориентир 2–3 классы РФ (без упражнений для 1 класса). Статический сайт в `index.html` без зависимостей.

## Правила
- Сохраняй режимы: `mental` — «Вычитание», `sub` — вычитание столбиком, `add` — сложение в уме, `addcol` — сложение столбиком, `mul` — умножение, `div` — деление, `mix` — смешанный.
- Не упоминай «22 − 9» в названии вкладки «Вычитание». Такие примеры в упражнениях разрешены.
- Не показывай задания уровня 1 класса.
- Каждый навык развивается независимо; переход после 6 правильных ответов подряд; ошибка сбрасывает серию.
- Ни одно уже выданное задание не должно повторяться в истории текущего браузера, в том числе в листах для печати.
- Сохраняй существующий ключ localStorage `math_rf_unique_v1`; учитывай коммутативность прямого сложения и умножения при определении повторов.
- При исчерпании банка сообщай об этом явно. Не стирай историю автоматически.
- Проверяй арифметику программно, без вызовов LLM/API.
- Тренажёр должен работать на телефоне, на компьютере и на GitHub Pages.

## Перед коммитом
- Выполни `node tests/trainer.test.cjs`.
- Проверь все вкладки, проверку ответов, переход уровня, сохранение истории после перезагрузки, печать.
- Для GitHub Pages: `index.html` в корне репозитория, ветка `main`.
