# Математика — тренажёр без повторов

Веб-тренажёр для ребёнка, изучающего арифметику на уровне 2–3 классов РФ. Бесплатный, без регистрации и внешних API.

## Что умеет

- Вычитание в уме (режим называется **«Вычитание»**).
- Сложение в уме.
- Вычитание и сложение трёхзначных чисел столбиком.
- Табличное умножение и деление.
- Смешанная тренировка.
- 6 правильных ответов подряд — следующий уровень в конкретном навыке.
- История всех выданных примеров хранится в localStorage без повторов на одном устройстве и в одном браузере (включая задания для печати).
- Лист на 12 задач с ответами для родителя.

**Ограничения:** охватывает арифметические навыки 2–3 классов, но не всю федеральную школьную программу; история не синхронизируется между устройствами; удаление данных сайта удаляет историю.

## Запуск

Откройте `index.html` напрямую в браузере. Сборка и сервер не нужны.

## Публикация на GitHub Pages

В публичном репозитории откройте **Settings → Pages → Build and deployment**.
Выберите `Deploy from a branch`, ветку `main`, папку `/(root)`, нажмите **Save**.

После успешной публикации адрес:
https://cyberfightmg-spec.github.io/math-trainer-rf/

Это ожидаемый адрес, пока публикация не завершена, доступность не подтверждена.

## Работа в Codex

Откройте этот репозиторий в Codex. Инструкции для агента в `AGENTS.md`.
Основная страница — `index.html`. Для проверки без браузера выполните `node tests/trainer.test.cjs`.

Не менять ключ истории `math_rf_unique_v1` без миграции, иначе могут повторяться задания.
